# 智能反诈训练系统

> 识破一次，才能真正学会拒绝。

智能反诈训练系统是一款面向大学生的反诈训练 Web 应用。它不是一张把全部功能堆在一起的长页面，而是一个基于 **Vue 3 + Vue Router** 的多路由应用，将风险检测、报告阅读、情景演练、真实案例、成长记录和智能助手拆成独立页面。

技术文档：[MingBian-technical-document.pdf](docs/MingBian-technical-document.pdf)

## 产品功能

- **可疑消息检测**：逐句识别返利、垫付、屏幕共享、验证码和二次转账等风险信号。
- **训练情报台**：首页展示可交互风险雷达、训练情报轮播和本周风险热度；点击风险点可查看案例数量并直达案例或演练。
- **可解释风险报告**：按“风险诊断 / 核验依据 / 行动清单”查看结果。
- **真实新闻案例**：收录 11 条公开校园诈骗报道，点击卡片前往新闻原文。
- **压力情景演练**：AI 扮演兼职招聘者、假客服或假老师，用户练习拒绝和核验。
- **成长记录**：用本地数据展示综合防骗力、14 天训练活跃度、风险分布和八枚能力徽章。
- **AI 反诈助手**：结合本地知识库和公开案例回答问题，并展示信息来源。
- **安全档案**：记录常见风险场景和提示偏好，不要求手机号、身份证或真实账户。
- **登录与注册**：支持本地账户、演示体验账户和登录状态保护，密码加盐哈希后保存在当前浏览器。
- **知识训练中心**：十五个短课覆盖刷单、公检法、客服、校园贷、票务、游戏交易、投资理财、冒充熟人等主题。
- **每日安全挑战**：10 道情景判断题，服务端评分并返回逐题解释，成绩计入成长记录。

## 页面路由

| 路由 | 页面职责 |
|---|---|
| `/` | 产品首页、核心入口和任务闭环 |
| `/scan` | 可疑消息输入与风险检测 |
| `/report/:id` | 独立风险报告、证据与行动页 |
| `/practice` | 与 AI 进行反诈情景对话 |
| `/academy` | 十五个主题的反诈知识短课 |
| `/challenge` | 每日安全挑战与逐题复盘 |
| `/cases` | 真实新闻案例与原文跳转 |
| `/dashboard` | 本地检测及演练成长记录 |
| `/assistant` | 独立 AI 反诈助手 |
| `/profile` | 安全档案 |
| `/login` | 登录、注册与本地体验模式 |

顶部导航和当前路由状态持续保留。每个页面只承担一个主要任务，复杂信息通过标签页、侧栏和独立路由展开。

## AI 技术方案

- DeepSeek `deepseek-chat` 负责可疑消息解释、情景角色扮演和助手回答。
- 本地规则引擎负责稳定的风险特征命中与评分。
- 本地 RAG 知识库覆盖 15 类校园高频风险，并提供 10 个可交互演练场景。
- 每日挑战由服务端评分，公开题目接口不会返回正确答案。
- AI 输出经过服务端约束，模型不得索取真实密码或验证码。
- 无 API Key 或网络异常时自动使用本地规则与预设演练，主要流程仍可演示。
- 手机号、证件号、邮箱和银行卡号在模型调用前脱敏。

## 快速运行

```bash
cp .env.example .env
# 在 .env 中填写 DEEPSEEK_API_KEY
python3 server/app.py
```

打开 <http://127.0.0.1:8000>。

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

## 目录

```text
app/                  Vue 3 多路由前端
app/vendor/           本地 Vue 与 Vue Router 运行文件
server/               API、规则引擎、RAG、AI 助手和情景演练
data/                 反诈知识库与真实新闻案例
docs/                 架构、来源、演示和提交说明
tests/                核心后端测试
```

## 安全边界

智能反诈训练系统不会要求用户提交真实密码、验证码、银行卡号或身份证照片，也不会替用户联系警方、银行或任何第三方。模型输出只用于风险教育。若已经转账或泄露敏感信息，应立即联系银行，并拨打 110 或向学校保卫部门求助。
