# OfferGuard · 职途罗盘

> 看见每一份 offer 的隐藏代价。

OfferGuard 是面向高校毕业生的 AI 就业风险侦察 Agent。它把一份劳动合同从大段文字拆成可核验的风险证据：先保护隐私，再定位高影响条款，检索法规依据，给出行动清单，最后由用户确认后才生成沟通草稿。

## 为什么不是另一个聊天框

传统法律问答只在“问什么答什么”时有效。OfferGuard 把 AI 放进完整工作流：

1. **隐私屏障**：在发送给模型前脱敏手机号、身份证和邮箱。
2. **条款侦察**：按试用期、薪酬、工时、解约等主题切分原文。
3. **证据检索**：从本地可信知识库召回相关法规与解释，答案必须引用证据编号。
4. **风险引擎**：结合影响程度、时效性和可验证性计算风险分。
5. **人工决策门**：关键行动必须由用户确认，模型不会代替用户发送或签署。

## 核心能力

- DeepSeek 驱动的两阶段 Agent：规划检索 → 合成报告。
- 本地优先 RAG：无需向量数据库即可完成可解释的证据检索。
- 面向校园招聘场景的合同风险规则库与行动模板。
- 信息脱敏、引用校验、低置信度兜底和法务升级提示。
- 可导出的 Markdown 风险报告，以及便于评审复现的离线演示模式。
- 桌面端和移动端自适应界面。

## 快速运行

项目仅依赖 Python 标准库，无需安装第三方运行依赖。

```bash
cp .env.example .env
# 在 .env 中填写 DEEPSEEK_API_KEY
python3 server/app.py
```

打开 <http://127.0.0.1:8000>。如果暂时没有 API Key，点击首页的“载入示例”即可使用确定性的离线 Agent 演示。

也可以直接指定环境变量：

```bash
DEEPSEEK_API_KEY="your-key" python3 server/app.py
```

## 安全边界

OfferGuard 提供就业风险识别与沟通准备，不构成正式法律意见，也不替代执业律师。涉及高额违约金、工伤、歧视、扣押证件、人身安全或已经发生争议的情况，应尽快联系学校就业中心、劳动保障监察部门或专业律师。
