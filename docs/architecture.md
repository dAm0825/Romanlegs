# 明辨技术架构

## 产品结构

网站采用 Vue 3 与 Vue Router，所有页面共享顶部导航和品牌外壳，但拥有独立 URL、页面标题和任务边界：

```text
Vue App Shell
├── /                 首页
├── /scan             可疑消息输入
├── /report/:id       风险报告
├── /practice         AI 情景演练
├── /academy          知识与短课
├── /challenge        每日挑战
├── /cases            真实新闻案例
├── /dashboard        本地成长记录
├── /assistant        AI 反诈助手
├── /profile          安全档案
└── /login            登录 / 注册 / 体验账户
```

这种结构避免把输入、结果、建议、案例和聊天全部追加在一张长页面上。

## 请求链路

```text
浏览器
  │
  ├─ POST /api/detect ──► 规则引擎 → 知识库检索 → DeepSeek 合成 → 安全校验
  ├─ POST /api/practice ─► 情景状态 → DeepSeek 角色扮演 → 确定性风险复核
  ├─ POST /api/assistant ─► RAG 检索 → DeepSeek 回答 → 知识来源过滤
  ├─ GET  /api/news ──────► 公开新闻案例 JSON
  ├─ GET  /api/scenarios ─► 预置演练场景
  ├─ GET  /api/challenges ► 不包含答案的挑战题目
  └─ POST /api/challenges/grade ► 服务端评分与逐题解释
```

## 风险检测

1. 对输入做本地脱敏。
2. 规则库匹配刷单、公检法、客服、校园贷、票务、游戏交易和虚假招聘。
3. 对屏幕共享、验证码、安全账户等高风险动作额外加权。
4. 从本地知识库召回解释与真实案例。
5. 由 DeepSeek 生成更自然的解释与行动建议。
6. 将结果写入当前浏览器 localStorage，并进入独立报告路由。

## 情景演练

每个演练场景包含虚构开场、连续施压话术和训练目标。用户回复后：

- AI 继续扮演诈骗角色；
- 服务端判断是否出现验证码、屏幕共享、转账或贷款等配合动作；
- 返回反馈、更安全的替代回答和安全分变化；
- 对“我不会共享屏幕”等防御性表达做确定性纠正，避免简单地按关键词误判。

## AI 助手

助手先检索本地反诈知识和公开新闻，再把结果送入 DeepSeek。回答只允许引用提供的知识或案例，前端同时展示知识条目和新闻原文链接。

## 账户与训练模块

- 注册密码使用浏览器 Web Crypto 进行加盐 SHA-256 哈希，原始密码不写入 localStorage。
- 演示账户可以跳过注册直接体验。
- 成长记录、知识训练和每日挑战需要登录；登录后按原目标路由跳转。
- 知识训练保存已掌握课程；每日挑战保存最高成绩、完成次数与逐题解释。

## 隐私

- `.env` 不进入 Git；
- 本地安全档案不要求敏感联系方式；
- 检测时先脱敏手机号、证件号、邮箱和银行卡号；
- 检测摘要和演练记录只保存在 localStorage；
- 模型不得索取真实密码或验证码。
