## 录制清单

1. 浏览器缩放保持 100%，窗口比例 16:9。
2. 使用示例合同，确认页面显示 `DEEPSEEK AGENT ONLINE`。
3. 点击条款证据、切换筛选、勾选确认并生成草稿。
4. 录制时隐藏书签栏、密码管理器提示和通知。
5. 成片使用 H.264 MP4，分辨率 1920x1080，普通话讲解。
6. 将视频上传到可公开访问的平台，并在 README 和提交表中填写链接。
